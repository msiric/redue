admits A's stage/workspace and exact H code; unchanged H-targeting helpers cannot
satisfy their intended permitted workspace controls. This is a source/binding
finding, not a native execution failure.

the actual privately minted A fixture. Node/checker code locations alone move to
distinct H paths. Every A canary binding and both C assertion source bodies stay
unchanged. The private pair and H assets must match before and after rendering.

- Node's permitted workspace write changes write-canary bytes without restoring
  them. Its parent-symlink control also creates an extra workspace member.

  bytes return to their original value.

  names, changing timestamps. That does not revive the original exact snapshot.
- The stage-exchange helper requires exact workspace membership and original
  marker bytes; it cannot follow the Node helper on the modified fixture.

phase-specific observation contract before any combined route. Do not reset
mints, remove unexpected writes to obtain green, or adopt an old saved report.

host configuration. The original credential/read/write restrictions and native
execution boundary are unchanged. Original six-check closure stays separate.
