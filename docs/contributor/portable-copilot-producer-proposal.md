## Exact proposed local host boundary

The helper produces an uninstalled settings object and argv for the disposable
VM. Its readable runtime/prefix and writable checkout/state must be canonical,
owned paths. Private Copilot home, cache and log directories are separate and
denied to tools. The actual endpoint and ownership records must be displayed
before approval. No developer's private home or global settings are copied.

The proposal enables the native sandbox, forbids bypass, dev-tool credential/cache
grants, keychain, outbound/local network and git/gh authentication. Only shell
tools are available; native in-process file/web tools, delegation and built-in
MCPs are excluded. Only REDUE and limited inspection command stems are permitted.
Project instructions remain enabled. Authentication token names are passed to
`--secret-env-vars`, so the host authenticates but its command children must not
receive the tokens. This is a different documented facility from proxy masking:
no token-injection host or OS certificate-trust change is needed for offline
compiler execution. Other unexpected credential variables must stop preparation;
do not log their values.

Configured settings alone are insufficient. Before a model:

1. Confirm the effective managed policy in the actual host, with no global edits.
2. Run a no-model command through that host's actual sandbox boundary: intended
   REDUE config/state/socket works, unrelated paths/sockets and direct network do
   not, and command children lack authentication values. Do not treat help,
   an outside-shell preflight or a handcrafted sandbox as this proof.
3. Check actual caller-aware applicability after all installation/guidance changes.
   Missing prerequisites launch zero models. Origin creation and recipient reuse
   have different expected states; a producer without a receipt is not CURRENT.

MXC's macOS filesystem grants also govern Unix-socket access: a writable directory
grant permits endpoints below it. The proposed owned state directory must contain
only the intended observer endpoint. It is not an all-Unix-socket grant or a pure
read approval: that observer can reconcile, execute its reviewed configured probes,
reload and stop. If the effective policy exposes another endpoint or a private
credential path, stop for review. No unauthenticated proxy or unsandboxed helper.
