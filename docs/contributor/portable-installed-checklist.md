# Next exact installed portable candidate check

This is a bounded execution checklist, not new acceptance evidence. Reuse the
[recorded @1→@2 installed upgrade](portable-host-preflight.md) only while its code,
policy and tested conditions remain unchanged. Later candidate bytes still need
one exact-artifact check; retain the first hosted incomplete-origin failures.
Do not count source tests, package installation, model preflight or runner inventory
as successful actual cross-agent/machine reuse.

1. Record the full reviewed commit, actual `npm pack --json` filename, manifest and
   SHA-256. Verify bytes before installation; version text alone cannot identify
   unreleased candidates sharing alpha.10 metadata. Use owned prefixes/checkouts
   and state. Do not rebuild after validating or change a normal pilot install.
2. Install those bytes and inspect actual help/assets. Confirm the installed
   command is `redue`, export/import require local project/check selection, inspect
   works outside any project, and queued JSON previews are complete. Confirm
   `docs/user/portable-evidence.md`, shared policy and required native helper are
   actually in the package. Record the actual host/build/image/filesystem separately.
3. Complete all project/agent setup before the baseline. Preview direct recipe and
   apply explicitly; existing configs must not be overwritten. Setup/removal uses
   config-only selection and preserves user text/edited managed content; custom
   machine state requires the documented generic path. Keep exact state selection
   on observer/run/status/evidence commands. State is never transferred.
4. Execute the configured compiler with `run CHECK --portable`. Require the actual
   export preview's complete origin, not just local CURRENT/PASS; a failed gate
   launches zero models and transfers no artifact. Preserve real PASS/FAIL and
   static portable/checkpoint diagnosis even when the origin is incomplete. Do not
   warm runtime validation before cold capture or increase deadlines to hide failure.
5. Export into a new file outside source/state in an existing owned directory.
   Preview is no-write; disclosure paths are data and must be owner-reviewed. Check
   destination overwrite/symlink refusal and owner/selection barriers without
   executing imported code or leaking source/environment/credential-bearing values.
6. Inspect, then import into a separately initialized recipient with explicit local
   `--check`, exact reviewed manual digest and `--apply`. Preview creates no accepted
   state. Acceptance is not CURRENT; synchronize under the actual caller and require
   understood schema, healthy observation, CURRENT/PASS and explicit eligibility.
   Retain envelope digest and origin run ID, `evidence_source: imported`, no local
   invocation and no recipient execution record. Current input/receipt conflicts
   and observer loss must fail conservatively. Do not infer global chronology.
7. Reassess unrelated and relevant edits, membership/resolution changes and restart.
   Preserve source history and imported facts; relevant changes must prevent reuse.
   Preserve a newer FAIL after replay, failed reload and incomplete persistence.
   Changed/unsupported runtime/compiler/input/trust must not expose an older green.
8. Upgrade through actual preserved @1 bytes with the same config/state selection.
   Immutable old history survives; @2 inspection/import refuses @1 rather than
   upgrading its facts. Actual newer FAIL survives old PASS replay. Test public
   policy update/idempotence/removal and edited-content refusal while config/user
   text/import bytes remain intact. Setup metadata can legitimately invalidate;
   record the final normal reassessment instead of promising CURRENT.
9. Keep authentication separate: a CI import requires the current owner-approved
   local registry, reviewed verifier bytes and explicit apply. Missing/revoked trust
   or unavailable required refresh grants no authority. Manual file acceptance is
   not signed CI acceptance. Record current registry/digest binding; do not create
   trust from the imported artifact, instruction or GitHub account login.
10. Run affected shared/platform and exact-package acceptance. Portable eligibility
    remains limited to its actual reviewed profile, independently of Linux/Windows
    package mechanics. Actual matched machines, host models, authenticated route,
    complete-path economics and independent review retain their own plan gates.

Retain every attempted artifact/run and failure; clean only owned experiment
processes/prefixes after evidence is safely retained. No new model, signing, trust,
account or permission action is authorized by this checklist.
