# REDUE coordinator — lean delivery

Read [STATUS.md](../../STATUS.md) and AGENTS.md. They are the only mandatory
startup material. The canonical plan and detailed decisions remain references,
not a compulsory whole-history preamble. This is the existing REDUE-PE-001 goal;
no new coordinator, framework or goal is needed.

## Delivery loop

Take the highest-value unblocked item in STATUS. Work directly when that is
simplest; delegate bounded independent implementation/review/research when it
shortens delivery. One writer per interface; no mandatory director-only role.
Use at most4 agents including the coordinator within established included capacity.

Deliver a coherent user outcome per PR. Use targeted checks during development
and appropriate whole/platform checks at the integration/release boundary.
Independent review is required for selection, applicability, trust/authentication
and security-boundary changes. Review related code/bindings/tests together, in an
isolated checkout or exact Git objects. Ordinary changes need tests and normal CI.
A reviewer may test in an owned verification workspace where host permissions
permit it; source review and mock tests are not actual native/machine acceptance.

After two materially different failures, inspect evidence and alternatives,
including a narrower claim. Do not retry unchanged, start speculative machinery,
or extend deadlines silently. Freeze the current sealing experiment. The owner
approved evaluating a simpler controlled-CI contract; review and state its exact
assumptions before enabling a new interpretation. Retain old containment.
